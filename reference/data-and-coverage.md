# Данные и охват

Скринер и пользовательские оповещения организованы вокруг поддерживаемых **бессрочных фьючерсов с котировкой в USDT**; основной набор рынка — фьючерсы Binance. Это обзор деривативов, а не каталог спота. Не предполагается, что одноимённый инструмент другой площадки имеет те же цену, фандинг или объём.

## Какие инструменты входят

Список обновляется из биржевых данных и меняется вместе с листингами, делистингами и доступностью данных. Используйте актуальный список приложения, а не фиксированное число контрактов. Из этого представления USDT perpetual исключаются строки с котировкой USDC и срочные контракты.

Часть поддерживаемых деривативов может быть связана с акциями, индексами или товарами. **STOCK / АКЦИЯ** и **COMMODITY / ТОВАР** — классификационные бейджи. Такой ярлык не доказывает, что инструмент является токенизированной акцией, даёт права акционера или означает владение базовым активом. Проверьте спецификацию инструмента у биржи. Секторные бейджи, например AI или Meme, обозначают категории, а не торговые гарантии. Классификация может запаздывать относительно котировок; отсутствие бейджа не меняет спецификацию контракта.

## У свежести несколько этапов

Сервис получает сделки, цены, свечи, фандинг и OI с разной периодичностью и собирает доступные данные в снимки. Браузер по возможности использует поток, при необходимости — периодический запрос снимка. Полный снимок не означает одновременное измерение каждой исходной метрики.

Проверка оповещений читает общие рыночные данные независимо от браузера и передаёт совпадения в очередь доставки. Это отдельные этапы; интервал обновления данных не обещает такую же задержку уведомления. Экран и сообщение Telegram могут отражать разные моменты наблюдения.

Смотрите индикатор соединения и предупреждения об устаревании. При недоступности свежих данных сервис может сохранить предыдущий пригодный снимок или оставить отдельные значения пустыми. **—** означает недоступность, не ноль. Само наличие строки или графика не доказывает текущую доступность рынка.

## Окно определяет смысл

| Семейство | Что означает окно |
| --- | --- |
| Изменение и Изменение$ 5м / 15м / 1ч / 8ч | Скользящие сравнения по сохранённым наблюдениям или доступной свечной базе; момент базы может быть приближённым |
| Изменение / Изменение$ / Объём 24ч | Скользящее окно биржевого тикера, не календарные сутки |
| Объём / VDelta 5м | Последняя завершённая пятиминутная свеча |
| Объём / VDelta 15м / 1ч | Последние 3 / 12 завершённых свечей 5м, с шагом по их закрытиям |
| Объём / VDelta 8ч | Последняя завершённая восьмичасовая свеча |
| VDelta 1д | Последняя завершённая дневная свеча; отличается от скользящего Объёма 24ч |
| RVOL 5м / 15м / 8ч / 1д | Оборот завершённой свечи относительно исторической базы |
| RVOL 1ч | Сумма закрытых свечей 5м с базой из часового ряда; приближение |
| Объём свечи Δ 5м / 15м / 1ч | Текущая незавершённая свеча против предыдущей завершённой |
| Объём свечи Δ 8ч / 1д | Две завершённые свечи |
| Волатильность / Корреляция BTC | Статистика свечных доходностей по буферу из 20 свечей указанного интервала; неполная история ограничивает покрытие |
| Тики | Агрегированные торговые события за скользящее время |
| Изменение OI | Сравнение с периодическими историческими снимками; приближённые окна |

Метрики завершённых свечей обычно постоянны между закрытиями. Объём формирующейся свечи неполон и обычно мал в начале бара. Ни одно из этих свойств нельзя переносить на скользящее изменение цены.

## Единицы и интерпретация

Цена и оборот выражены в валюте котировки контракта — здесь USDT; `$` используется в продукте как сокращение. Номинал в USDT не является денежным балансом или оценкой исполнения заявки. Объём — оборот, не вновь вложенный капитал.

Процентные значения записаны в процентах. Рост цены со 100 до 103 — +3%. Изменение фандинга с 0,01% до 0,02% — рост на **0,01 процентного пункта**, или удвоение в относительном выражении. Фандинг указан за расчётный период контракта, не в годовом исчислении; интервалы расчёта могут различаться.

Долларовый OI — открытое количество, оценённое по текущей цене. Изменение OI % сравнивает количества, а долларовая часть оценивает разницу количеств по текущей цене. Они не определяют депозиты, плечо или сторону, инициировавшую позиции. VDelta показывает разницу тейкерского оборота, а не чистые лонги. Тики — агрегированные события, а не уникальные люди или отдельные исполнения.

RetailHeat связывает число событий с оборотом и имеет основной и сглаженный расчёты. Окна исходных величин могут отличаться; это не точная обратная величина среднего размера сделки и не классификатор розничных и институциональных участников.

## Сравнивайте сопоставимое

При проверке другого источника сопоставьте биржу, полный контракт, валюту котировки, тип цены, определение метрики, окно и время. Внешние графики TradingView и Coinglass могут иметь другое сопоставление рынков или агрегированные индикаторы. Резервный источник на сервере не превращает приложение в скринер с пользовательским выбором биржи; происхождение данных важно, когда требуется точное соответствие площадке.
