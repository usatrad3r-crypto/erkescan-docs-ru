# Подключение аккаунта к Журналу

Откройте [Журнал](https://app.erkescan.com/ru/journal) и выберите подключение или добавление аккаунта. Если аккаунт уже есть в списке, восстанавливайте подключение и меняйте ключ в его Настройках. Второй журнал того же биржевого аккаунта может продублировать историю в общем виде.

## Bybit: ключ только для чтения

1. Войдите в тот аккаунт или субаккаунт Bybit, историю которого хотите загрузить. Откройте **API Management → Create New Key**.
2. Выберите **Read-Only**. Следуйте текущей подсказке Журнала по правам: включите предлагаемые права чтения, оставив вывод средств выключенным. Не используйте торговый ключ Vertex.
3. В ErkeScan выберите правильную среду. Ключ Demo относится к Demo, а не к Live.
4. Вставьте API-ключ и API-секрет в форму Журнала. Выберите доступный период истории и нажмите **Подключить и импортировать**.
5. Дождитесь проверки ключа и импорта. Откройте Журнал и проверьте аккаунт и время обновления.

Журнал только читает аккаунт. Торговые права ему не нужны, даже если некоторые ключи с расширенными правами принимаются с предупреждением. Отдельный ключ Read-Only даёт Журналу только необходимый доступ.

В подключении Bybit может предлагаться необязательное ограничение по IP. Если вы его используете, скопируйте текущий IP, показанный Журналом, в настройки этого ключа на Bybit. Для уже ограниченного по IP ключа запросы Журнала должны быть разрешены. **IP-подсказка Журнала и полный список IP для копитрейдинга — разные настройки.**

Не записывайте API-секрет в заметки и не отправляйте поддержке. Если биржа отклонила ключ, сначала прочитайте причину: неверную среду или неподдерживаемый тип аккаунта повторная вставка тех же значений не исправит.

## Hyperliquid: публичный адрес кошелька

Выберите Hyperliquid и вставьте полный публичный адрес кошелька, с которого торгуете. Он начинается с `0x`, после которых идут 40 символов. Нужен адрес основного торгового кошелька, а не API-кошелька.

API-секрет, приватный ключ, seed-фраза и подпись торговой операции не нужны. Публичный адрес позволяет Журналу читать открытые торговые данные, но не даёт права торговать или выводить средства.

Выберите предлагаемый период истории, подключите кошелёк и запустите импорт. Если список сделок пуст, сначала проверьте адрес. Среда Hyperliquid Demo в этом подключении Журнала не предлагается.

## Проп-испытания

Если нужно отслеживать поддерживаемое испытание CFT, выберите вариант проп-аккаунта. Укажите программу, этап и размер счёта, затем пройдите подключение Bybit Demo. Если форма предлагает подходящий личный Demo-аккаунт, можно связать испытание с ним и сохранить историю в одном месте.

Перед заменой ключа в активном испытании прочитайте предупреждение: правила провайдера могут ограничивать такие изменения. Актуальные условия проверяйте у провайдера; отслеживание в Журнале не разрешает менять их.

## Как проходит первый импорт

Проверка ключа обычно занимает секунды, первый импорт — несколько минут; ориентируйтесь на фактический статус. По мере поступления данных страница обновляется. Доступную историю ограничивают выбранный период и покрытие API биржи.

| Результат | Что делать |
| --- | --- |
| Подключено, импорт идёт | Дождитесь завершения или откройте Журнал, пока данные поступают. |
| Подключено, первый импорт не начался | Повторите импорт либо запустите его из Настроек аккаунта. Только из-за этого переподключать ключ не требуется. |
| Импорт на паузе | Прочитайте сообщение. Если пауза на стороне сервиса, продолжение не требует держать страницу открытой. |
| Требуется действие | Выполните указанное действие на бирже и вернитесь. |
| Статус импорта недоступен | Задача может продолжать работу. Повторно проверьте статус, прежде чем считать импорт неудачным. |
| Импорт завершён, сделок нет | Проверьте аккаунт, среду, период и наличие в нём поддерживаемых закрытых сделок. Пустой период возможен. |

После первого импорта Журнал продолжает загружать новую поддерживаемую историю. Проверяйте актуальность обновления, особенно перед сравнением итогов с биржей. Подробнее — [Разбор сделок и восстановление данных](review-and-troubleshoot.md).
