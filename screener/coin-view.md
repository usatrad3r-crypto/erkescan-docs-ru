# Карточка монеты и страница символа

Посмотреть на цену одной монеты внутри ErkeScan можно двумя способами: графиком, который открывается поверх таблицы, и отдельной страницей символа. Здесь разобраны оба и то, для чего каждый нужен.

## График в модальном окне

В десктопе нажмите на **текст тикера** внутри ячейки символа — например на слово `BTC`. Поверх таблицы откроется панель с графиком.

- Это график **TradingView** по **бессрочному контракту Binance** для этой монеты, открытый на **15-минутном** интервале, в тёмной теме.
- Закрывается по **Escape**, кнопкой **×** или кликом в любом месте затемнённого фона.
- **Full Page →** (открыть полную страницу) открывает отдельную страницу символа в новой вкладке браузера, а ваш скринер остаётся ровно в том состоянии, в котором вы его оставили.

График открывает только текст тикера. Остальная часть строки на клик не реагирует, а чекбокс избранного рядом с тикером — отдельный элемент: он отмечает монету звездой и ничего не открывает.

Поскольку на графике тот же бессрочный контракт Binance, это тот же рынок, который описывают числа скринера. График и строка говорят об одном и том же.

{% hint style="info" %}
График нужен для структуры цены — где находится движение относительно диапазонов, максимумов и прошлых реакций. Метрик скринера на нём нет. За [RVOL](../glossary.md), [VDelta](../glossary.md), [открытым интересом](../glossary.md), [фандингом](../glossary.md) и остальным возвращайтесь в строку. Смысл именно в паре: см. [От строки в таблице до сделки](from-screen-to-trade.md).
{% endhint %}

## На телефоне

При ширине меньше 768 пикселей вместо таблицы рисуются карточки, и вся карточка является ссылкой: тап по ней уводит на страницу символа этой монеты. Исключение — кнопка-звезда в правом верхнем углу карточки: тап по ней добавляет или убирает монету из избранного и никуда не уводит.

## Страница символа

У каждой монеты есть своя страница по адресу `/symbols/<СИМВОЛ>`. Попасть на неё можно через **Full Page →** в модальном окне, тапом по карточке на телефоне или набрав адрес вручную.

**Что требуется.** Активная подписка. Вошедший пользователь без подписки увидит вместо графика страницу с предложением оформить подписку.

**Что принимается.** Тикер в адресе нормализуется, поэтому несколько написаний ведут на одну и ту же страницу — `trb`, `TRB`, `TRB-USDT` и формы вроде `BTCUSDT.P` открываются корректно. Пустые и бессмысленные значения, а также голое слово `USDT`, сразу отдают 404.

**Что показывает.** График TradingView по этому символу и «хлебные крошки», чтобы вернуться назад.

**Как проверяет.** Страница сверяет ваш тикер с живым списком фьючерсов Binance и отдаёт 404 для символов, которых там нет. Эта проверка **не блокирует при сбое**: если в этот момент список недоступен, страница всё равно нарисует график. То есть нарисованный график сам по себе не доказывает, что контракт сейчас торгуется.

{% hint style="warning" %}
**Страницы-списка `/symbols` не существует.** Обращение к `/symbols` отдаёт 404. Страница символа — это то, куда вы приходите из строки, а не каталог, по которому можно ходить. Чтобы найти монету, пользуйтесь полем **Поиск...** в скринере.
{% endhint %}

## Что выбрать

| Ситуация | Что использовать |
|---|---|
| Быстро проверить структуру, не отрываясь от таблицы | График в модальном окне — закрывается по Escape и сохраняет ваше место |
| Долго изучать одну монету, рисовать на графике | Страницу символа в отдельной вкладке |
| Сравнить несколько монет на одном окне | Ни то ни другое — [Страница графиков](charts.md) |

**Далее:** [Страница графиков](charts.md) — пять панелей, которые ставят монету в контекст её когорты.
