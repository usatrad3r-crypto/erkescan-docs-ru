# Добро пожаловать в ErkeScan

ErkeScan объединяет скринер рынка, сигналы стратегий и торговые инструменты в одном веб-приложении. Начните с вашей задачи:

| Ваша задача | Куда перейти |
| --- | --- |
| Найти активные фьючерсные рынки и собрать избранное | [Скринер](https://app.erkescan.com/screener) |
| Получать Telegram-сообщения по своим условиям | [Пользовательские оповещения](alerts/how-alerts-work.md) |
| Следить за стратегиями или изучить причину движения | [Сигналы и Radar](signals/choose-a-tool.md) |
| Подключить автоматическое исполнение сигналов Vertex на своём Bybit | [Копитрейдинг](copy-trading/overview.md) |
| Разбирать свои сделки | [Торговый журнал](journal/overview.md) |
| Сравнивать активность рынков или изучать опционные уровни | [Графики](https://app.erkescan.com/charts) и [GEX](gex/overview.md) |

Скринер, пользовательские оповещения и Графики работают с бессрочными фьючерсами Binance в USDT. У остальных разделов свои рынки, требования к подключению и правила доступа. Уведомление о сигнале не выставляет ордер. Копитрейдинг — отдельная функция: для неё нужны подключение биржи, настройки риска и явный запуск.

## Если вы впервые

1. [Создайте аккаунт](getting-started/create-your-account.md).
2. [Выберите тариф](getting-started/choose-a-plan.md). Перед оплатой сравните срок и итоговую стоимость.
3. [Подключите Telegram](getting-started/connect-integrations.md), если хотите получать сообщения. Для привязки не нужно покупать ещё одну подписку.
4. Пройдите [первые 15 минут в скринере](getting-started/first-steps.md) или откройте нужный продукт из таблицы выше.

На стандартной странице тарифов нет общедоступного бесплатного пробного периода. До покупки можно изучить публичные страницы стратегий. Живые уровни премиум-сигналов и платный скринер требуют активного доступа. Подписка сама по себе не запускает копитрейдинг и не подключает биржевой аккаунт.
