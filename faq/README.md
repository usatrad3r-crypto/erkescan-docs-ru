# Частые вопросы

Вопросы, которые люди действительно задают перед покупкой и сразу после неё — честно и коротко.
Каждый ответ ведёт на страницу с полной версией.

## Самые быстрые ответы

| Вопрос | Короткий ответ |
|---|---|
| Какой рынок покрывается? | Только бессрочные фьючерсы Binance с маржой в USDT — примерно 670 контрактов, около 140 из них токенизированные акции и товары. [Подробно](../reference/data-and-coverage.md) |
| Сколько это стоит? | $200 за месяц, $468 за три, $868 за год. Все три плана открывают ровно одно и то же. [Подробно](../getting-started/choose-a-plan.md) |
| Есть пробный период? | Нет. Ни пробного периода, ни бесплатного тарифа. |
| Сколько можно завести алертов? | 200, на любом плане. [Подробно](../alerts/how-alerts-work.md) |
| Куда приходят алерты? | В Telegram, через **@erkescanalert_bot**. Пока ваш чат в Telegram не привязан к аккаунту, не отправляется ничего. [Как привязать](../getting-started/connect-integrations.md) |
| Как отсортировать колонку? | Маленькой кнопкой-стрелкой рядом с заголовком. Сам текст заголовка перетаскивает колонку. [Подробно](../screener/personalize.md) |
| Деньги списываются автоматически? | Нет. Каждый платёж разовый, продлеваете вы сами, когда захотите. |
| Куда писать? | [@ErkeScanSupportbot](https://t.me/ErkeScanSupportbot) или support@erkescan.com. [Подробно](../reference/support.md) |
