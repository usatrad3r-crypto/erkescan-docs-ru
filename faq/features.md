# Возможности и инструменты

Что на самом деле дают скринер, алерты, страница графиков и премиум-каналы — и чего они не дают.

### По чему можно фильтровать в скринере

Четыре инструмента, которые работают вместе:

* **11 кнопок быстрых фильтров** над таблицей: Все, Выс. объём, Скачок OI, Движение, Выс. фандинг, Накопление, Сквиз, Пробой, Топ-10 активных, Топ роста 24ч, Топ падения 24ч. Одновременно активна одна. У каждой фиксированное правило, они перечислены в [быстрых фильтрах](../screener/quick-filters.md).
* **Сортировка** по поддерживаемым колонкам, кнопкой-стрелкой рядом с заголовком. У Тренда сортировки нет.
* **Поиск**, чтобы найти символ по подстроке без учёта регистра. Это не выбор нескольких тикеров через запятую.
* **Избранное**, чтобы закрепить наверху монеты, за которыми вы реально следите.

Метод, как собрать из этого реальный отбор, — в [как собрать свой фильтр](../screener/build-your-own-filters.md).

### Можно ли сохранить свой фильтр

Нет. Ни сохранённых фильтров, ни конструктора фильтров здесь нет. В браузере сохраняются раскладка колонок, плотность и избранное — поэтому на практике отбор пересобирается кнопкой фильтра и сортировкой, а это пара секунд.

### Можно ли фильтровать или ставить алерты по капитализации

Нет. В скринере и форме пользовательских оповещений нет поля капитализации: ни колонки, ни фильтра, ни условия. Все метрики здесь берутся из активности фьючерсного рынка — цена, объём, открытый интерес, фандинг, поток сделок.

### Есть ли колонка корреляции с ETH

Нет. Корреляция считается только **с BTC**, на пяти окнах (5м, 15м, 1ч, 8ч, 1д). КОРР. BTC (1ч) показана по умолчанию, остальные включаются в выборе колонок.

### Как отсортировать колонку

Нажмите **маленькую кнопку-стрелку** рядом с текстом заголовка. Сам текст — это ручка для перетаскивания колонки, поэтому нажатие на него двигает колонку, а не сортирует. Сначала выберите быстрый фильтр, потом сортируйте оставшиеся строки. Выбор другого фильтра сбрасывает сортировку.

### Сколько алертов можно создать

**200 на аккаунт**, одинаково на любом плане. Попытка номер 201 вернёт «Alert limit reached (max 200). Delete unused alerts to create new ones.» — «Достигнут лимит алертов (макс. 200). Удалите неиспользуемые, чтобы создать новые». Подробности — в [как работают алерты](../alerts/how-alerts-work.md).

### По каким метрикам можно ставить алерты

29 условий в 7 группах:

| Группа     | Поля                               |
| ---------- | ---------------------------------- |
| Change     | 5m, 15m, 1h, 8h, 24h               |
| OI Change  | 5m, 15m, 1h, 8h, 1d                |
| Volume     | 5m, 15m, 1h, 8h, 24h               |
| VDelta     | 5m, 15m, 1h, 8h, 1d                |
| Volatility | 5m, 15m, 1h                        |
| Ticks      | 5m, 15m, 1h                        |
| Others     | Price, Open Interest, Funding Rate |

Группы Volatility, Ticks и VDelta — всего 11 условий — спрятаны за переключателем **Show advanced fields** (показать дополнительные поля), который по умолчанию свёрнут.

На часть колонок скринера алерт поставить нельзя вообще: RVOL, корреляция с BTC, семейство ИЗМ.$, ОБЪЁМ СВЕЧИ Δ и RetailHeat. Если колонки нет в таблице выше, алерта по ней не будет.

{% hint style="warning" %}
**Change (8H)** использует скользящее восьмичасовое изменение цены в процентах. Условием можно пользоваться так же, как другими окнами Change; выбирайте подходящий окну порог и проверяйте все условия вместе.
{% endhint %}

### Можно ли выбрать таймфрейм графика в сообщении алерта

Для отдельного оповещения таймфрейм выбрать нельзя. Сервис пытается приложить **15-минутный** график; если картинка недоступна, сообщение может прийти только текстом.

### Можно ли скопировать существующий алерт

Да. Выберите действие копирования у оповещения. На новой карточке «Черновик» нажмите карандаш: откроется форма нового оповещения с параметрами исходного. Проверьте название и условия, затем сохраните; исходное оповещение останется отдельным.

### Переезжают ли колонки и избранное на другое устройство

Нет. Видимость колонок, их порядок, плотность и избранное хранятся в том браузере, где вы их задали. В другом браузере, на другом устройстве или после очистки данных сайта появится раскладка по умолчанию из 19 колонок, без избранного.

### Что есть на странице графиков

Пять панелей на тех же живых данных, что и скринер: сводная полоса для трейдера, график ротации по цене, график ротации по открытому интересу, гистограмма распределения доходностей и таблица фандинга из двенадцати монет с самой большой ставкой по модулю.

Вы выбираете одну из четырёх когорт — **Top Gainers 24h, Top Losers 24h, Top Volume 24h, Top Active 5m** — и одно из пяти окон: 1H, 4H, 1D, 1W, 1M, по умолчанию 4H. По умолчанию на графике рисуется шесть символов.

Группы на странице Графики и таблица фандинга требуют минимум $500,000 часового оборота. Такой порог есть и у трёх фильтров топ-10 скринера; он не относится ко всем быстрым фильтрам. Подробности — в [графиках](../screener/charts.md).

### Можно ли посмотреть график одной монеты

Двумя способами. Клик по тикеру в таблице открывает график TradingView по этому бессрочному контракту Binance в модальном окне — закрывается по Escape, по крестику или кликом мимо. Либо откройте `app.erkescan.com/symbols/<ТИКЕР>` как отдельную страницу: нужна активная подписка, и списка символов для просмотра там нет. См. [карточку монеты](../screener/coin-view.md).

### Акции и товары правда есть в крипто-скринере

Да, потому что Binance торгует их как бессрочные фьючерсы. В списке могут быть бессрочные контракты, связанные с акциями и товарами, с бейджем **АКЦИЯ** или **ТОВАР**, если тип определён. Список меняется. Такие инструменты не дают права собственности на базовые акции или товары.

Режим торговли, источник цены и ликвидность каждого контракта сверяйте по спецификации биржи. Не предполагайте, что часы торговли бессрочным контрактом совпадают с часами базовой акции или товара.

### Покрывает ли ErkeScan спот или другие биржи

Скринер и его пользовательские оповещения покрывают бессрочные фьючерсы Binance в USDT. У других инструментов ErkeScan свои источники и рынки, включая Bybit для копитрейдинга Vertex. О скринере см. [данные и покрытие](../reference/data-and-coverage.md).

### Что я получаю помимо скринера

Пользовательские оповещения, Графики и [каталог сигналов](../premium/overview.md) дополняют [Копитрейдинг](../copy-trading/overview.md), [Торговый журнал](../journal/overview.md) и [GEX](../gex/overview.md). У каждого продукта свои условия доступа и подключения. Членство в сообществе — отдельный путь; обычная подписка не является записью на курс.
